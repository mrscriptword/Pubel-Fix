# Pubel (Pusat Berbagi Lokal) 🚀

**Pubel** adalah aplikasi berbagi file revolusioner yang dirancang untuk menyederhanakan cara Anda memindahkan data antara smartphone dan PC. Tanpa kabel, tanpa software tambahan di PC, dan sepenuhnya berjalan di jaringan lokal Anda.

![Pubel Banner](https://raw.githubusercontent.com/mrscriptword/Pubel/main/design_preview.png)

## ✨ Fitur Unggulan

Aplikasi ini dirancang dengan fokus pada kecepatan, keamanan lokal, dan pengalaman pengguna yang premium.

### 🌐 Berbagi via Browser (Web Share)
Ubah HP Anda menjadi server portabel. Cukup ketik alamat IP yang muncul di aplikasi ke browser PC Anda (Chrome, Edge, Firefox) untuk langsung mengakses file. Tidak perlu menginstal apapun di sisi PC.

### ⚡ Kecepatan Tanpa Batas (Local Transfer)
Karena berjalan di jaringan Wi-Fi lokal, kecepatan transfer tidak dibatasi oleh kuota internet Anda. Kirim file berukuran GB dalam hitungan detik.

### 📂 Smart File Manager
Manajemen file yang cerdas dengan kategorisasi otomatis:
- **Foto**: Akses cepat ke galeri foto Anda.
- **Video**: Streaming atau unduh video langsung ke PC.
- **Musik**: Kelola koleksi audio dengan mudah.
- **Dokumen**: Berbagi laporan, PDF, dan dokumen kantor lainnya.

### 🎨 Antarmuka Modern & Dinamis
Desain yang terinspirasi dari estetika modern dengan:
- **Glassmorphism**: Efek transparan yang elegan.
- **Dark & Light Mode**: Nyaman di mata dalam kondisi cahaya apapun.
- **Animasi Radar**: Visualisasi transfer data yang interaktif.

### 🔒 Keamanan & Privasi Total
Data Anda tidak pernah menyentuh internet. Proses transfer terjadi sepenuhnya secara Peer-to-Peer di dalam jaringan rumah atau kantor Anda sendiri.

---

## 🛠️ Arsitektur Teknologi

- **Flutter Engine**: Performa UI yang mulus dan responsif.
- **Local HTTP Engine**: Menggunakan server *shelf* yang berjalan langsung di kernel aplikasi.
- **Network Discovery**: Pendeteksian IP cerdas untuk kemudahan koneksi.
- **Cloud Build Integration**: Automasi build APK melalui GitHub Actions untuk rilis yang cepat.

## 📦 Download APK
Versi terbaru selalu tersedia di tab **Actions** pada repositori ini. Cukup pilih build terbaru dan unduh dari bagian *Artifacts*.
